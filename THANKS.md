# Thanks

Thunder is a list of other people's work. This repository holds the list, a few configs and the scripts that install it. Every machine, spell, mob and biome in the game was made by the people below.

Nothing about Thunder is sold, so what it can give back is credit. Each mod stays under its own author's licence, and nothing here claims otherwise. The pages linked below are where to find their releases and the rest of their work.

## Also Standing On

- [packwiz](https://github.com/packwiz) is how the pack is published and installed.
- [Minecraft Forge](https://minecraftforge.net/) loads all of it.
- [Eclipse Temurin](https://adoptium.net/) is the Java the scripts fetch when a machine has no Java 17 or 21.
- The server install is built around the egg format and yolk images from [Pterodactyl](https://pterodactyl.io/).

## Where This List Comes From

Each entry is read from the pack's own metadata: every `mods/*.pw.toml` and `resourcepacks/*.pw.toml` names the Modrinth or CurseForge project it installs. Authors are that project's team as listed there on 28/09/2026, owner first, or the organisation that publishes it. When a mod joins or leaves the pack, this file changes with it, by hand.
