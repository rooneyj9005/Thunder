Installation

The whole thing takes a couple of minutes. Here's what to do.

Before you start

You'll need three things:

  • Java 21. Most launchers sort this out for you. If yours doesn't, grab it from Adoptium.
  • A launcher that supports Modrinth packs. We recommend Prism Launcher. It's free, open-source, and works on Windows, Mac, and Linux. ATLauncher also works.
  • About 8 GB of RAM to spare. The pack runs 123 mods, so it needs a bit of room to breathe. 6 GB is the bare minimum; 8 GB is comfortable.

Installing the pack

1

Download the pack

Head to the home page and hit Download Latest. Save the .mrpack file somewhere you'll be able to find it again.

2

Import it into Prism Launcher

Open Prism Launcher, click Add Instance, then choose Import on the left. Browse to the .mrpack you just downloaded and click OK.

3

Hit play

Double-click the new Thunder instance. On the first launch, the launcher downloads all the mods for you. Just wait for it to finish. After that, Minecraft opens and you're in.

The first launch takes longer than usual because it's downloading 123 mods. After that, it starts at normal speed.

Giving it enough memory

If the game stutters or crashes with an out-of-memory error, you probably need to bump up the RAM allocation. Here's how in Prism Launcher:

  1. Right-click the Thunder instance and choose Edit.
  2. Go to Settings → Java.
  3. Tick Memory and set the maximum to 8192 MB (that's 8 GB).
  4. Close and launch again.

Don't go above 10 GB. It sounds counterintuitive, but giving Java too much memory actually makes things worse because garbage collection pauses get longer and you end up with frame drops. 8 GB is the sweet spot.

Updating to a new version

If you imported the .mrpack into Prism Launcher, updates are handled automatically. The instance includes a prelaunch command (update.ps1) that syncs pack files before every launch, so you stay up to date without doing anything.

If you need to update manually:

  1. Download the new .mrpack from the home page.
  2. Import it in Prism Launcher (or any Modrinth-compatible launcher). Creating a new instance is recommended for easy rollback.
  3. Move your saves folder (and optionally options.txt) into the new instance if needed.

Once you've confirmed the new version works, you can keep the old instance as a backup or remove it. Server operators should use the startup.sh or startup.ps1 scripts instead -- see the server setup guide.
