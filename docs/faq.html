Frequently Asked Questions

If your question isn't here, open an issue on GitHub and we'll sort it out.

How much RAM do I need?

Give Minecraft at least 6 GB, ideally 8 GB. That's enough for all 123 mods to run comfortably. Going above 10 GB actually makes things worse because Java's garbage collector takes longer pauses and you'll notice frame drops. The installation guide explains how to change this in Prism Launcher.

Can I add my own mods on top?

Yes. You can install your own mods, but you should understand how Thunder's managed files work.

The pack core is kept in sync by the updater so the base experience stays stable and supportable. That means some custom dependency chains or config combinations may not survive updates if they rely on managed paths.

As a rule of thumb: extra utility mods and shader tooling are often fine, while worldgen, rendering internals, and core gameplay mods are more likely to conflict.

What files are managed, and what is usually left untouched?

Managed files are files with explicit entries in Thunder's pack index (index.toml). On update, those indexed files may be restored to the pack's expected state.

  • Managed: specific indexed files, often under paths such as mods/, config/, defaultconfigs/, and kubejs/.
  • Usually untouched: extra files you add with unique names/paths that do not collide with managed files.
  • Will be replaced: files that use the same filename/path as a managed file.

Is OptiFine compatible?

No. OptiFine is not supported and commonly conflicts with modern Forge mod stacks.

Thunder already includes performance-focused mods such as Canary, Krypton, and Memory Leak Fix. If you want shaders, use Oculus (Forge shader loader) with shader packs, not OptiFine.

The game crashes on startup. What's going on?

Nine times out of ten, this is either a RAM issue or a Java version issue.

  • Make sure you're running Java 21.
  • Make sure you've given Minecraft at least 6 GB of RAM.
  • If you added extra mods, try removing them and launching again.

Still crashing? Check the log file at logs/latest.log inside your instance folder. Search for "Error" or "Exception". The log usually names the exact mod that's causing trouble.

How do I update when a new version comes out?

If you imported the .mrpack into Prism Launcher, you don't need to do anything. The instance includes a prelaunch command that syncs pack files automatically before every launch.

If you need to update manually, download the latest .mrpack from the home page, import it in your launcher, and copy your saves folder (and optionally options.txt) into the new instance.

Server operators should use startup.sh or startup.ps1, which run packwiz sync by default. See the server setup guide for details.

Is the auto-updater safe, and can I disable it?

Fair question. Some players see any auto-updater as a potential backdoor. Thunder only syncs pack files listed by pack.toml and index.toml, and you can disable sync if you want full manual control.

Managed files can be restored to pack defaults. Extra files with unique names are usually left alone unless they collide with a managed path.

If you disable the updater and edit the pack directly, you are effectively forking your local install. That is fine for advanced users, but future Thunder updates will likely overwrite those changes unless you stay pinned to your current version.

If you've disabled auto-update, try updating to the latest Thunder release before filing an issue.

  • Linux: run PACKWIZ_SKIP_UPDATE=true bash startup.sh
  • Windows: run .\startup.ps1 -SkipPackUpdate

Why does Thunder avoid bundling every optional tool?

We keep Thunder as neat as possible so players can customise it. Every extra built-in tool can lock users into specific workflows or create more compatibility burden in the core pack.

The goal is a stable base that works out of the box, while still leaving room for advanced users to layer their own preferences.

How do I connect to a server running Thunder?

Install the pack on your machine using the installation guide, then add the server's IP address through the multiplayer menu. You and the server need to be on the same version of the pack.

Does voice chat work automatically?

Yep. Thunder includes Simple Voice Chat. On a server that has it installed (which it will if the server was set up using the server guide), just be near another player and talk. Press V to open the voice chat settings. No extra setup needed.

The game runs but it's really laggy. Help?

A few things to try:

  • Make sure you've allocated 8 GB of RAM (but not more than 10).
  • Drop your render distance to 8-10 chunks in video settings.
  • Close Chrome. Seriously, it's probably eating your RAM.
  • Check that your graphics drivers are up to date.

Is there a Pterodactyl egg for this pack?

Yes. The repository includes a ready-made egg template that handles Forge installation and mod synchronisation automatically. Import it through your panel's Nests section. The server setup guide has the full steps.

What Java version do I need?

Java 21. Most launchers (Prism, ATLauncher) handle this for you automatically. On Windows, install.ps1 downloads Temurin 21 if Java isn't found, so you don't need to set it up yourself. On Linux, install Java 21 before running install.sh. Grab it from Adoptium.

Can I run a server on Windows?

Yes. The repository includes PowerShell scripts (install.ps1 and startup.ps1). install.ps1 handles everything including downloading Java 21 if it isn't installed. Open PowerShell in an empty folder, run .\install.ps1, then .\startup.ps1. The server setup guide has the full steps.

Do I need to use Pterodactyl to host a server?

No. The install scripts work on any Linux or Windows machine. Pterodactyl is just one option. You can run install.sh (or install.ps1 on Windows) on a VPS, a spare PC, or anywhere else you can run Java. The scripts handle Forge installation and mod downloads for you.

Do I need to port forward?

If you're hosting from home, yes. You'll need to forward port 25565 (TCP) for Minecraft and port 24454 (UDP) for Simple Voice Chat. If you're renting a VPS or using a hosting panel, ports are usually handled for you. Check with your provider if you're not sure.

Can I change the modlist on my server?

You can, but clients connecting to your server will need matching mods. If you add server-side-only mods (permissions, anti-grief, etc.) those won't affect clients. If you add mods that change gameplay or add new items, every player will need them installed too. The safest option is to stick with the official modlist.

Where do I report bugs or suggest changes?

Open an issue on the GitHub repository. If the game is crashing, paste your crash log. It makes things much easier to diagnose.
