Frequently Asked Questions

If your question isn't here, open an issue on GitHub and we'll sort it out.

How much RAM do I need?

Give Minecraft at least 6 GB, ideally 8 GB. That's enough for all 112 mods to run comfortably. Going above 10 GB actually makes things worse because Java's garbage collector takes longer pauses and you'll notice frame drops. The installation guide explains how to change this in Prism Launcher.

Can I add my own mods on top?

You can, but fair warning: all 112 mods in Thunder have been tested together. Dropping in extra mods, especially ones that touch world generation, rendering, or core game mechanics, might cause crashes or strange behaviour. Small utility mods and shader packs are usually fine.

Is OptiFine compatible?

No, and you don't need it. OptiFine conflicts with several mods in the pack. Thunder already includes Canary, Krypton, and Memory Leak Fix, which handle performance optimisation. If you're after shaders, look into Oculus (a Forge-compatible shader loader) instead.

The game crashes on startup. What's going on?

Nine times out of ten, this is either a RAM issue or a Java version issue.

  • Make sure you're running Java 17 or newer.
  • Make sure you've given Minecraft at least 6 GB of RAM.
  • If you added extra mods, try removing them and launching again.

Still crashing? Check the log file at logs/latest.log inside your instance folder. Search for "Error" or "Exception". The log usually names the exact mod that's causing trouble.

How do I update when a new version comes out?

Download the new .mrpack from the home page and import it into Prism Launcher as a new instance. If you want to keep your worlds, copy the saves folder from the old instance before you delete it. The installation guide has the full steps.

How do I connect to a server running Thunder?

Install the pack on your machine using the installation guide, then add the server's IP address through the multiplayer menu. You and the server need to be on the same version of the pack.

Does voice chat work automatically?

Yep. Thunder includes Simple Voice Chat. On a server that has it installed (which it will if the server was set up using the server guide), just be near another player and talk. Press V to open the voice chat settings. No extra setup needed.

The game runs but it's really laggy. Help?

A few things to try:

  • Make sure you've allocated 8 GB of RAM (but not more than 10).
  • Drop your render distance to 8–10 chunks in video settings.
  • Close Chrome. Seriously, it's probably eating your RAM.
  • Check that your graphics drivers are up to date.

Is there a Pterodactyl egg for this pack?

Yes. The repository includes a ready-made egg template that handles Forge installation and mod synchronisation automatically. Import it through your panel's Nests section. The server setup guide has the full steps.

Where do I report bugs or suggest changes?

Open an issue on the GitHub repository. If the game is crashing, paste your crash log. It makes things much easier to diagnose.
